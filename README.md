# AI Security Learning Journal

> A personal journey from using AI to understanding how AI systems can be secured, attacked, trusted, and monitored.

## About This Project

This public journal documents how my understanding of AI Security evolves from the perspective of a cybersecurity professional.

Rather than collecting definitions, I question each concept, connect it with realistic security scenarios, correct my assumptions, and record what changed in my thinking.

> **Learn → Question → Understand → Apply → Share**

## Content and Attribution

This repository contains my own explanations, questions, corrections, examples, and cybersecurity interpretations developed while studying AI Security through educational and primary industry sources.

The learning journey includes the TryHackMe AI Security learning path alongside official references and my previous cybersecurity and incident-management experience.

It intentionally does not reproduce labs, flags, credentials, assessment answers, challenge solutions, proprietary prompts, lab infrastructure, or step-by-step walkthroughs.
